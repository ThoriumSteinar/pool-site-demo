# АкваЛайн — сайт по услугам бассейна

**Живой сайт:** https://thoriumsteinar.github.io/pool-site-demo/

Учебный одностраничный сайт вымышленной компании по обслуживанию бассейнов.
Чистый HTML, CSS и JavaScript — без сборки и без npm.

Опубликован через GitHub Pages: ветка `main`, папка `/` (корень).
После `git push` сайт пересобирается сам, обновление занимает около минуты.

## Файлы

```
pool-site/
├── index.html      # вся разметка и тексты
├── styles.css      # стили (цвета в :root сверху)
├── script.js       # меню, анимация, калькулятор, форма
├── images/         # фотографии
│   ├── company-team.png       # команда мастеров
│   ├── pool-stone-terrace.jpg
│   └── pool-wood-deck.jpg
└── README.md       # этот файл
```

## Как открыть

**Вариант 1 — двойной клик.** Открой `index.html` в браузере.

**Вариант 2 — Live Server (удобнее).** Правый клик по `index.html` → **Open with Live Server**.
Страница сама обновляется после сохранения.

**Вариант 3 — Python.** Из этой папки:

```bash
python -m http.server 8080
```

Потом открой `http://localhost:8080`.

## Что можно править

- **Тексты** — прямо в `index.html`, секции подписаны комментариями.
- **Цвета и шрифты** — в `styles.css`, блок `:root` в самом начале.
- **Цены калькулятора** — в `script.js`, объект `SERVICES`: `base` это выезд, `perCubic` — цена за кубометр.
- **Новая услуга** — скопируй блок `<article class="service-card">` и поменяй текст.
- **Новый вопрос** — скопируй блок `<details class="faq-item">`.

## Как добавить своё фото

1. Положи файл в папку `images/`.
2. В `index.html` найди секцию «Работы» и скопируй блок `<figure class="gallery-item">`.
3. Поменяй в нём три вещи:
   - `src="images/твой-файл.jpg"` — путь к фото;
   - `width` и `height` — настоящие размеры файла в пикселях (браузер заранее знает место под фото и страница не «прыгает» при загрузке);
   - `alt="..."` — описание для тех, кто не видит картинку.

Фото в галерее подгружаются лениво (`loading="lazy"`) — браузер скачивает их
только когда ты доскроллил. У главного фото в hero такого атрибута нет: оно видно сразу.

Кадры обрезаются под соотношение 3:2 через `object-fit: cover` — фото не растягивается,
а подрезается по краям. Соотношение меняется в `styles.css` в правиле `.gallery-item img`.

## Как считает калькулятор

```
объём = длина × ширина × глубина
цена  = base + объём × perCubic
```

Например 8 × 4 × 1.5 = 48 м³, сезонное обслуживание: 2500 + 48 × 90 = 6 820 ₴.

## Важно

Компания, цены, телефон и почта — **выдуманные**, только для практики.
Форма заявки никуда не отправляется: JavaScript проверяет поля и показывает сообщение на странице.
